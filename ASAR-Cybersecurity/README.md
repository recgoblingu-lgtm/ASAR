## Welcome to ASAR

Welcome to the ASAR cybersecurity class. This course is for anyone who wants to learn more about cybersecurity, online safety, and ethical hacking in a clear and understandable way.

You do not need to be an expert to join. The class is being built for people who are interested in technology and want to learn how to protect themselves, their accounts, and their systems. Whether you are completely new to cybersecurity or already have some experience, there will be something useful for you to learn.

## What You Will Learn

The class will cover topics such as:

- Cybersecurity basics

- Online privacy and personal safety

- Account and password security

- Common threats and vulnerabilities

- How scams, phishing, and social engineering work

- Network and device security

- Ethical hacking concepts

- Safe security testing

- Basic server security and management

- How to learn from open-source software

The course may also include information about Rec Room revival server development and the security considerations that come with running and managing servers.

## Ethical Hacking and Responsible Use

Cybersecurity skills should always be used responsibly. Any demonstrations, tools, or exercises in this class are meant for learning and authorized testing only.

Only test systems that you own or have clear permission to test. Never use what you learn here to break into accounts, steal information, damage systems, disrupt services, or invade someone’s privacy.

> If you do not have permission, do not test it.

Learning ethical hacking means learning both the technical skills and the responsibility that comes with them.

## Who Is This Class For?

This class is a good fit for:

- Beginners who want to start learning cybersecurity

- Students interested in ethical hacking

- People who want to improve their online safety

- Future server owners and developers

- Anyone interested in technology and open-source projects

## About ASAR

ASAR is a free project that offers learning resources and courses related to cybersecurity, ethical hacking, and Rec Room revival server development. The goal is to create a welcoming community where people can learn, practice, and share knowledge without needing to pay for access.

The project is still in development, so the course content and documentation may change over time as new lessons and resources are added.
